# 이미지 프롬프트 템플릿 (Nano Banana Pro)

이미지는 글당 **1회 생성**이 원칙. 생성한 일러스트에 텍스트가 필요하면
Canva 에서 따로 합성한다 (이미지 안에 글자를 넣어 생성하지 않는다).

## 규칙
- **인물 없음** — 사람 얼굴/손 등 미포함 (저작권·일관성 리스크 회피)
- **텍스트 없음** — 글자는 Canva 합성용으로 비워둔다
- 스타일: 플랫 일러스트 / 부드러운 파스텔 / 네이버 모바일 피드에서 눈에 띄는 톤
- 비율: 1:1 또는 4:3 (네이버 블로그 썸네일 친화)

## 프롬프트 형식

```
{{핵심 사물/장면을 영어로 묘사}}, flat illustration style,
soft pastel colors, no text, no people, clean composition,
{{분위기 키워드}}, 4:3 aspect ratio
```

## 예시 — 키워드 "홈카페 원두 보관"

```
a glass jar of coffee beans on a wooden kitchen shelf,
flat illustration style, soft pastel colors, no text, no people,
cozy warm morning light, clean minimal composition, 4:3 aspect ratio
```

## Canva 합성 가이드
- 생성된 일러스트를 배경으로 깔고, 제목 텍스트를 상단 1/3 영역에 배치
- 폰트는 블로그 정체성에 맞춰 1~2종으로 고정
- 텍스트 대비를 위해 반투명 박스 또는 그라데이션 오버레이 사용
