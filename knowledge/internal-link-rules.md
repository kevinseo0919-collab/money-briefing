# 내부 링크 그물망 규칙 (v1.0)

## 1. 링크 개수
- 글 1개당 최소 2개, 최대 4개의 다른 글로 연결
- 같은 카테고리 1~2개 + 다른 카테고리 1개 + 시리즈 연결 1개

## 2. 링크 위치
- 본문 중반부 (전체 글의 50~70% 지점)에 1개
- 마지막 단락 직전 "관련해서 함께 읽으면 좋은 글" 박스에 2~3개

## 3. 링크 형식 (네이버 블로그 호환)
> 💡 **함께 읽으면 좋은 글**
> - [부모급여 2026 실제로 얼마 들어오나](placeholder-url)
> - [어린이집 보육료 지원 자격](placeholder-url)

발행 전 placeholder-url을 실제 네이버 블로그 URL로 교체

## 4. 카테고리별 자연스러운 연결 매핑
- 사장님 금융 → 정책이슈 (사업자 대상 정부 지원금)
- 정책이슈 → 육아경제 (가족 단위 정책)
- 육아경제 → 돈 일기 (가계 운영)
- 돈 일기 → 사장님 금융 (사업자 가계부)

## 5. 앵커 텍스트 작성 원칙
- 글 제목 그대로 사용 금지 (어색함)
- 자연스러운 문맥 삽입: "월세 부담 줄이는 방법은 [주거급여 신청 글]에서 자세히 다뤘어요"
- 키워드 자연 포함
