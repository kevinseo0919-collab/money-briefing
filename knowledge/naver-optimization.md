# 네이버 로직 최적화 규칙 (v1.0)

## 1. C-Rank 누적 전략
- 주제 집중도: 한 주에 1~2개 카테고리만 발행 (분산 발행 금지)
- 주차별 시리즈 구조:
  · 1주차: 사장님 금융 (5건)
  · 2주차: 정책이슈 (5건)
  · 3주차: 육아경제 (5건)
  · 4주차: 돈 일기 (3건) + 회고 (2건)
- 이전 글 내부 링크 필수 2개 이상 삽입

## 2. D.I.A.+ 체류시간 최적화
- 본문 길이: 1,500~2,500자 (너무 길면 이탈, 너무 짧으면 깊이 부족)
- 단락당 3줄 이내, 단락 사이 빈 줄 필수
- 본문 중간 1/3 지점에 "잠깐, 핵심만 다시 정리할게요" 같은 시선 잡는 박스
- 마지막 단락에 댓글 유도 질문 1개 (질문은 매번 다르게)
- 관련 글 내부 링크 2개 (체류시간 연쇄 효과)

## 3. AI 패턴 회피 (중요)
도입부 5종 로테이션 (요일별 고정):
- 월요일: 질문형 - "○○, 정말 받을 수 있는 거 맞을까요?"
- 화요일: 숫자형 - "작년에 제가 받은 ○○만원, 어떻게 챙겼냐면요"
- 수요일: 실수담형 - "3년 전 제가 놓쳤던 거 하나 때문에…"
- 목요일: 시즌형 - "○월 ○일, 이 날짜 놓치면 끝납니다"
- 금요일: 인용형 - "어제 거래처 사장님이 저한테 물어보시더라고요"
- 토요일: 비교형 - "A안과 B안, 어떤 게 저한테 맞을까 고민됐는데요"
- 일요일: 발견형 - "이거 모르고 1년을 흘려보냈어요"

마무리 5종 로테이션 (랜덤):
- 응원형: "오늘도 작은 한 걸음 응원해요"
- 약속형: "다음 글에서는 ○○ 다뤄볼게요"
- 질문형: "여러분은 어떻게 하고 계신가요?"
- 정리형: "오늘 핵심만 다시 짚으면 ○○이에요"
- 경험형: "저는 이렇게 하고 있어요, 참고만 하세요"

## 4. 인간미 강제 삽입 요소 (글마다 최소 3개)
- 구체적 숫자: "47만원", "5월 31일 오후 11시 59분" (어림수 금지)
- 감정 표현: "당황했어요", "한숨 나왔어요", "안도했어요"
- 시간/장소 디테일: "아침 출근길 지하철에서", "둘째 재우고 새벽 1시에"
- 실패 경험: 성공담만 쓰지 말고 놓친 것·후회한 것 1개 포함
- 망설임 표현: "솔직히 저도 헷갈리는데요", "이 부분은 저도 확신 못 해요"

## 5. 발행 간격 규칙 (어뷰징 회피)
- 하루 최대 1건 발행 (절대 다발 발행 금지)
- 발행 시간대 분산: 매일 다른 시간 (오전 7시, 오후 1시, 저녁 7시 중 랜덤)
- 같은 카테고리 글 사이 최소 24시간 간격
- 주 6일 발행, 1일은 강제 휴식 (D.I.A.+ 자연스러운 패턴)

## 6. 키워드 배치 자연화
- 제목 정확 키워드 1회, **맨 앞에 배치**(front-load) — 반복 금지. 상세는 §8 제목 작성 규칙.
- 본문 첫 100자 안에 키워드 1회
- 본문 전체 키워드 밀도 1.5~2.5% (3% 넘으면 키워드 스터핑 의심)
- 동의어/유의어 적극 활용 (예: "신청 자격" = "받을 수 있는 사람" = "대상자")

## 7. 멀티미디어 다양성
- 글 1개당 이미지 최소 3장 (썸네일 + 본문 2장)
- 이미지 alt 텍스트에 키워드 자연 포함
- 가능하면 본문에 표 1개 + 인용박스 1개 + 코드/리스트 1개 혼합
- 네이버 클립(15~30초) 1개 삽입 시 체류시간 +40% 효과

## 8. 제목 작성 규칙 (상위 노출 패턴 반영 · 2026-05-25 적용)
> 근거: 주간 분석(05/18~05/24) — 상위 글은 ① 키워드를 제목 맨 앞에 두고 ② 질문형 제목이 30~40% ③ 구체 숫자·연도를 자주 쓴다. 내 블로그는 키워드 위치 혼재·질문형 3%로 격차가 컸다.

### 8-1. 키워드 front-load (P1, 필수)
- 제목은 **정확히 대상 키워드로 시작**한다. 키워드 앞에 수식어·인사·연도·이모지를 두지 않는다.
  - 좋은 예: "버팀목 전세자금대출 조건, 나도 될까요?"
  - 나쁜 예: "2026년 꼭 알아야 할 버팀목 전세자금대출" (키워드가 중간)
- 키워드는 제목에 1회만 (반복 금지).

### 8-2. 제목 유형 요일 로테이션 (P2, 질문형 비율 ↑)
도입부 로테이션과 **별개로** 제목 유형도 요일별로 돌린다. 질문형이 전체의 40% 이상이 되도록 배분한다(상위 30~40% 대비 격차 해소). 키워드 front-load(8-1)는 유형과 무관하게 항상 지킨다.

| 요일 | 제목 유형 | 형태 |
|---|---|---|
| 월 | 질문형 | "[키워드] 조건, 나도 해당될까요?" |
| 화 | 숫자형 | "[키워드] ○가지 조건 총정리 (2026년)" |
| 수 | 질문형 | "[키워드] 신청 자격은 어떻게 되나요?" |
| 목 | 숫자형(시즌) | "[키워드] ○월 ○일 마감, 월 ○○만원" |
| 금 | 질문형 | "[키워드], 지금 신청해도 될까요?" |
| 토 | 후기형 | "[키워드] 신청해보니 (실제 후기)" |
| 일 | 후기형 | "[키워드] 믿었다가 놓친 것 하나" |

→ 질문형 3/7(43%) · 숫자형 2/7 · 후기형 2/7.
- 질문형: 끝에 물음표(?)를 둬 검색 의도와 일치시킨다. (주간 분석기는 `?`로 질문형을 카운트)
- 숫자형: 키워드 다음에 숫자(○가지·월 ○○만원 등)를 둔다. (분석기는 `숫자+만원/원`을 숫자형으로 카운트)
- 후기형: "후기", "신청해보니", "놓친 것" 등 경험 신호어를 쓰되 본문과 어긋나는 과장은 금지.

### 8-3. 구체 숫자·연도 삽입 (P3, 권장)
- 가능하면 제목에 구체 숫자·연도를 넣는다: "5가지", "월 30만원", "주 15시간", "(2026년)", "(2026 최신)".
- 어림수("많이", "대부분") 대신 정확 숫자. 숫자는 §8-1 키워드 다음에 배치한다.

### 8-4. 길이·금지
- 제목 30자 내외(공백 포함 35자 이내 권장 — 모바일 검색 결과 잘림 방지).
- 금지어: "최고", "비법", "꿀팁", "100%", "보장", "무조건" (brand-facts.md 5번 준수). 본문과 불일치하는 클릭베이트 금지.
