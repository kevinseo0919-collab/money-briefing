# 후킹 멘트 작성 규칙 (v1.0)

## 적용 위치
모든 발행 초안의 ## 이미지 프롬프트 코드블록 바로 아래.

## 형식 규칙
- 정확히 2문장
- 각 문장 15자 이내 (공백 제외)
- 1문장과 2문장 사이 빈 줄 1개
- 마침표 없음, 문장부호 최소화

## 구조 규칙 (Sugarman Slippery Slide)
- 1문장: 충격/문제 제기 → 독자가 "어 나도?" 반응
- 2문장: 손실 암시 또는 해결 약속 → 본문 클릭 유도

## 6대 원칙
1. 손실 회피 우선 (얻는 이득보다 놓치는 손실)
2. 1인칭 경험 ("저처럼", "저도")
3. 구체적 시간·숫자 (5월 31일, 3.3%)
4. 독자 머릿속 문장 (이미 하는 생각)
5. 추상명사 금지 (성공, 행복, 최고)
6. 첫 문장은 갈고리, 둘째 문장은 약속

## 금지어
"최고", "비법", "꿀팁", "100%", "보장", "확실히", "무조건"
(brand-facts.md 5번 항목 준수)

## 좋은 예시
- "개인카드로 사업비 결제 / 저처럼 후회합니다"
- "3.3% 다 떼였는데 / 환급은 못 받아요"
- "5월 31일 안 넘기면 / 돌려받을 돈 있어요"

## 나쁜 예시
- "최고의 절세 방법" (금지어 + 추상)
- "프리랜서 필독" (구체성 0)
- "환급 100% 비법" (금지어 2개)
