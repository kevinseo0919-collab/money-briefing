# 해시태그 작성 규칙 (v1.0)

## 적용 위치
모든 발행 초안에서 ## 이미지 프롬프트 섹션 바로 위.
본문 끝나고 빈 줄 → ## 해시태그 → 빈 줄 → 태그들 → 빈 줄 → ## 이미지 프롬프트 순서.

## 형식 규칙
- 정확히 10개 (8~12개 사이 허용)
- 한 줄에 4~5개씩 줄바꿈으로 가독성 확보
- # 뒤 공백 없음 (#태그 O, # 태그 X)
- 태그 안에 공백 없음 (#사업용카드 O, #사업용 카드 X)
- 한글·숫자만 사용, 특수문자 금지
- 중복 금지

## 10개 구성 비율
- 핵심 키워드 변형: 2~3개 (예: 사업용카드 → #사업용카드 #사업자카드 #법인카드)
- 타깃 독자: 2개 (예: #자영업자 #프리랜서세금)
- 시즌·연도: 1~2개 (예: #2026종소세 #5월신고)
- 주제 카테고리: 2개 (예: #절세팁 #경비처리)
- 브랜드 고정: 2개 (필수: #케빈의돈이야기 + 카테고리명)

## 카테고리별 브랜드 고정 태그
- 사장님 금융 → #케빈의돈이야기 #사장님금융
- 정책이슈 → #케빈의돈이야기 #정책지원금
- 육아경제 → #케빈의돈이야기 #육아경제
- 돈 일기 → #케빈의돈이야기 #돈일기

## 금지 태그
- 절대금지어 포함 (#최고 #비법 #꿀팁 #100프로)
- 불명확 태그 (#좋아요 #맞팔)
- 본문과 무관한 태그

## 좋은 예시 (사업용카드 분리 글)

#사업용카드 #사업자카드분리 #법인카드 #홈택스등록
#종합소득세 #자영업자 #사장님재테크 #2026종소세
#케빈의돈이야기 #사장님금융
