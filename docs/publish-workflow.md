# 네이버 블로그 PC 발행 워크플로

마크다운으로 작성한 `feed-pool/*.md` 초안을 네이버 블로그 PC 에디터에 붙여넣어 발행하는 절차입니다.
변환 스크립트는 본문 마크다운(`**`, `##`, `>`, `-` 등)을 **변환 없이 그대로** 출력합니다.
굵게·소제목·인용구 서식은 붙여넣은 뒤 마커를 보면서 네이버 에디터 서식 도구로 직접 적용하고, 마커 기호는 직접 지웁니다.

## 발행 순서

1. `npm run publish feed-pool/<파일명>.md` 실행
2. `output/publish/<파일명>.txt` 파일 열기
3. `[본문]` 섹션 복사
4. 네이버 블로그 PC 글쓰기에 붙여넣기
5. 본문에 남아있는 `**`, `##`, `>` 등 마커를 보면서 해당 부분에 네이버 에디터 서식 적용 (B 버튼, 소제목 버튼, 인용구 버튼)
6. 서식 적용 후 마커 기호(`**`, `##`, `>`)는 직접 삭제
7. 사진 삽입, 해시태그 추가, 발행
