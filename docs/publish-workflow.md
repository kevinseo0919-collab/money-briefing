# 네이버 블로그 PC 발행 워크플로

마크다운으로 작성한 `feed-pool/*.md` 초안을 네이버 블로그 PC 에디터에 붙여넣기 위한 절차입니다.
원본 마크다운(`**굵게**`, `>` 인용 등)은 그대로 보존하고, 발행 시점에만 HTML 로 변환합니다.

## 1. 변환 실행

```bash
npm run publish feed-pool/<파일명>.md
```

→ `output/publish/<파일명>.txt` 가 생성됩니다.

## 2. 변환 파일 열기

`output/publish/<파일명>.txt` 를 엽니다. 다음 4개 블록으로 구성됩니다.

- `[블로그 발행용 - PC HTML 모드]` : 제목·카테고리·태그 (작성 시 참고)
- `[본문 - HTML 모드에 붙여넣기]` : 실제로 붙여넣을 HTML 본문
- `[해시태그 - 본문 끝에 추가]` : 발행 시 본문 맨 끝에 추가
- `[참고용 - 발행에는 사용하지 않음]` : 이미지 프롬프트·썸네일 후킹 멘트

## 3. 네이버 HTML 편집 모드 진입

1. 네이버 블로그 PC 글쓰기 진입
2. 우측 상단 `…` (더보기) 클릭
3. `HTML 편집` 클릭

## 4. 본문 붙여넣기

`[본문 - HTML 모드에 붙여넣기]` 섹션 내용을 복사해 HTML 편집창에 붙여넣습니다.

## 5. 에디터 모드 복귀 + 확인

`Editor` (일반 편집) 모드로 복귀하면 굵게·인용박스·소제목이 시각적으로 적용된 것을 확인할 수 있습니다.

## 6. 사진 삽입

사진은 일반 편집 모드에서 사진 버튼으로 직접 삽입합니다. (HTML 모드에서 이미지 삽입 금지)

## 7. 해시태그 추가

`[해시태그 - 본문 끝에 추가]` 의 태그들을 본문 맨 끝에 붙여넣습니다.

## 8. 발행

제목·카테고리를 확인하고 발행합니다.

## 9. 재수정 시 주의사항

- 재수정은 **일반 편집(Editor) 모드에서만** 수행하고 저장합니다.
- 한 번 발행한 글에 **HTML 모드로 재진입하지 마세요.** 스타일이 미세하게 변형될 위험이 있습니다.
- 텍스트 내용을 크게 바꿔야 하면 원본 `feed-pool/*.md` 를 수정한 뒤 다시 `npm run publish` 로 변환하는 편이 안전합니다.

## 변환 규칙 참고

| 마크다운 | HTML 변환 |
|---|---|
| `**굵게**` | `<b>굵게</b>` |
| `## 소제목` | `<h3>소제목</h3>` |
| `### 작은소제목` | `<h4>작은소제목</h4>` |
| `> 인용` | `<blockquote>인용</blockquote>` (연속 `>` 라인은 하나로 병합) |
| `- 항목` | `• 항목` (네이버 리스트 깨짐 방지용 불릿 문자) |
| `[텍스트](URL)` | `<a href="URL">텍스트</a>` |
| `---` | `<hr>` (수평선) |

frontmatter(`---` 사이) 와 `## 해시태그` / `## 이미지 프롬프트` / `## 썸네일 후킹 멘트` 섹션은 본문 변환에서 제외되어 별도 블록으로 분리됩니다.
