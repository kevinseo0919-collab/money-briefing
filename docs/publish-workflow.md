# 네이버 블로그 PC 발행 워크플로

마크다운으로 작성한 `feed-pool/*.md` 초안을 네이버 블로그 PC 에디터에 붙여넣어 발행하는 절차입니다.
변환 스크립트는 마크다운 마커(`**`, `##`, `>`, `-` 등)를 제거한 **깨끗한 일반 텍스트**를 만들어 줍니다.
굵게·소제목·인용구 서식은 붙여넣은 뒤 네이버 에디터 서식 도구로 직접 적용합니다.
원본 마크다운은 그대로 보존됩니다.

## 발행 순서

1. 글 작성 완료 후 `npm run publish feed-pool/<파일명>.md` 실행
2. `output/publish/<파일명>.txt` 파일 열기
3. 동시에 `feed-pool/<파일명>.md` 원본 파일도 별도 창으로 열어두기 (서식 위치 참고용)
4. 네이버 블로그 PC 글쓰기 진입
5. `[본문 - 네이버 에디터에 그대로 붙여넣기]` 섹션 내용을 복사해서 본문에 붙여넣기
6. 원본 `.md` 파일을 보면서 서식 적용:
   - `**xxx**` 로 감싸진 부분 → 네이버 에디터에서 해당 텍스트 드래그 → B(굵게) 버튼
   - `## xxx` 줄 → 해당 줄 클릭 → 소제목 H3 버튼
   - `### xxx` 줄 → 해당 줄 클릭 → 소제목 H4 버튼
   - `> xxx` 줄들 → 해당 부분 드래그 → 인용구(") 버튼
7. 사진은 사진 버튼으로 원하는 위치에 삽입
8. 해시태그를 본문 맨 끝에 추가
9. 발행
10. 재수정 시: 글 목록에서 `수정` 클릭 → 일반 편집 모드에서 텍스트 자유롭게 수정 가능

## 변환 규칙 참고

| 마크다운 | 변환 결과 |
|---|---|
| `**굵게**` | `굵게` (마커 제거) |
| `## 소제목` | `소제목` (앞뒤 빈 줄 보존) |
| `### 작은소제목` | `작은소제목` (앞뒤 빈 줄 보존) |
| `> 인용` | `인용` (`>` 기호만 제거) |
| `- 항목` | `• 항목` |
| `[텍스트](URL)` | `텍스트 (URL)` |
| `---` 구분선 | 빈 줄 |

frontmatter(`---` 사이) 와 `## 해시태그` / `## 이미지 프롬프트` / `## 썸네일 후킹 멘트` 섹션은 본문 변환에서 제외되어 별도 블록으로 분리됩니다.

## 이 방식의 장점

- 붙여넣은 본문이 **100% 일반 텍스트** — 별표·HTML 태그가 화면에 노출되지 않습니다.
- 재수정 시 네이버 일반 편집 모드에서 글자 수정·문단 추가·사진 교체가 자유롭습니다.
- 단점: 글 한 편당 서식 적용에 약 5~10분이 추가로 듭니다.
