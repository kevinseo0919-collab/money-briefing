# 홈피드(홈판) 노출 로직 v1 — 머니브리핑

> 설계일 2026-06-01 · 구현: `scripts/homefeed-gate.js` · 근거: 네이버 공개 동작원리 + 검색 실측 + 자체 피드 검증

---

## 0. 먼저, 정직하게

네이버는 홈피드 알고리즘을 **공개하지 않고**, 추천은 **개인화(사용자별)** 이며, 신규 블로그는 **3~6개월 신뢰 구축기**를 거친다. 그래서 "이렇게 하면 100% 홈판에 뜬다"는 **존재하지 않는다.**

대신 우리가 할 수 있는 건 이것이다:

> **홈피드에 뜬 글들이 공통으로 만족하는 "필요조건"을 게이트로 만들고,
> 모든 발행 글이 그 게이트를 통과하도록 강제한다.
> 통과 = 노출 "자격" 충족 / 미통과 = 노출 거의 불가.
> 그리고 발행 후 실제 유입경로로 검증해 게이트를 계속 보정한다.**

이게 "무조건"에 **구조적으로 가장 가깝게** 가는 유일한 방법이다. (요행 노출 ❌ → 자격 100% + 확률 최대화 → 데이터로 수렴 ✅)

---

## 1. 홈피드가 글을 미는 원리 (리서치 종합)

| 신호 | 내용 | 출처 근거 |
|---|---|---|
| 개인화 추천 | 사용자 행동(클릭·체류·저장·공유)으로 "이 사람이 좋아할 글" 매칭 | 홈피드 = AI 개인화 피드 |
| 초기 반응 | 발행 직후 소수 노출(테스트) → 반응 좋으면 증폭 | 행동 데이터 기반 확산 |
| 경험·진정성 | AI 초안이라도 **개인 경험·인사이트 재작성 필수** | DIA+ / 저품질 필터 |
| 스마트블록 적합 | 검색의도 단일 + 요약 스니펫 + 표 비교 = 블록 선택 | 2026 스마트블록 |
| 품질 > 양 | 고품질 1개 > 저품질 5개 | 홈피드 노출 가이드 |
| 광고글 페널티 | 협찬·리드젠 과다 피드는 노출 부진 | 홈피드 부진 원인 |
| 신뢰 구축기 | 신규 3~6개월 / 기존 2~4주 내 반응 | 신뢰도 누적 |

→ 머니브리핑 현 위치: 개설 ~3주. **아직 신뢰 구축 초기**다. 지금은 "게이트를 100% 통과한 글을 쌓아 신뢰를 빠르게 적립"하는 구간. 2~4주 뒤부터 반응이 붙기 시작한다.

## 2. 3-레이어 게이팅 로직

### Layer 0 — 블로그 체급 (글 단위 아님, 전제조건)
- ✅ 주제 일관성: 4시리즈 이내 집중 (이미 충족 — 사장님금융/정책이슈/돈일기/육아경제)
- ✅ 발행 일관성: 매일 정시 (충족)
- ⚠️ 신뢰 구축기: ~3주차 → **3개월까지는 "양보다 질" + 게이트 100% 통과로 신뢰 적립**
- ⚠️ 저품질·광고 누적 회피: 리드젠/협찬 톤 글 비율 최소화

> Layer0 권고: **다작(10개/일) → 노림수 2~3개 풀세팅 + 나머지 검색용으로 분리.** 홈피드는 "평균 품질"이 아니라 "터진 1개"가 끌고 가고, 저품질 다작은 신뢰 적립을 오히려 늦춘다.

### Layer 1 — 하드 게이트 (하나라도 실패 = 홈피드 탈락) 🚪
`scripts/homefeed-gate.js` 가 자동 판정.

| 게이트 | 판정 기준 | 왜 |
|---|---|---|
| G1 경험형 진정성 | 1인칭·감정 표현 ≥ 3 | DIA+/저품질 필터 통과 |
| G2 구체 숫자 | 금액·%·기한 숫자 ≥ 3 | 정보 신뢰·스마트블록 |
| G3 스니펫 | 「…」 한 문장 요약 존재 | 스마트블록이 뽑아갈 요약 |
| G4 구조화 | 표 또는 한눈정리 1개↑ | 스마트블록 비교 노출 |
| G5 가독성 | 짧은 줄·빈 줄·친근체 (v4.0) | 홈피드 체류시간 |
| G6 저장 유발 | 신청기한/체크리스트/"저장" 장치 | 홈피드 증폭 핵심 신호 |
| G7 길이 | 공백제외 1,100~2,600자 | 완독률·정보성 균형 |
| G8 광고 과다 아님 | 리드젠 톤·별표볼드 없음 | 광고글 페널티 회피 |

### Layer 2 — 점수 신호 (가점, 합 ≥ 8 이면 "노림수") 🎯
| 신호 | 가점 |
|---|---|
| S1 제목 공식(숫자+손실회피) | +2 |
| S2 기한/마감 후킹 | +2 |
| S3 질문형 후킹 제목 | +1 |
| S4 내부링크 2개↑ | +1 |
| S5 고단가 브리지 주제 | +1 |
| S6 경험형 강(1인칭 ≥5) | +1 |
| S7 숫자 풍부(≥6) | +2 |

- **🔴 하드게이트 탈락** → 발행 전 보완 필수
- **🟡 게이트 통과 / 점수 < 8** → 노출 자격은 OK, 검색용으로 발행
- **🟢 게이트 통과 / 점수 ≥ 8** → **홈피드 노림수**. 썸네일·발행시각까지 풀세팅 후 골든타임 발행

### Layer 3 — 사후 검증 루프 (확정에 수렴하는 유일한 길) 🔁
발행 후 24~48h, 네이버 블로그 통계에서:
1. 유입경로에 **"네이버 홈피드/추천"** 잡힌 글 = 실제 홈판 노출 → ✅ 라벨
2. 저장수·평균체류 기록
3. ✅ 글들의 공통 점수 패턴 분석 → **게이트 가중치(`CFG`) 보정**
4. 반복하면 게이트가 "이 블로그의 실제 홈피드 공식"으로 수렴

> 이 루프가 없으면 위 게이트는 추측이다. 루프가 있으면 게이트가 매주 똑똑해지고, "무조건 노출"에 점근(漸近)한다.

## 3. 사용법

```bash
# 단일 글 판정
node scripts/homefeed-gate.js feed-pool/132-파킹통장_추천_순위.md

# 이번주 활성 전체 일괄 + 요약
node scripts/homefeed-gate.js feed-pool/*.md

# JSON (파이프라인 연동용)
node scripts/homefeed-gate.js feed-pool/132-*.md --json
```

권장 연동:
- **발행 전 필수**: 노림수 글은 `homefeed-gate` 🟢 확인 후 발행
- `/blog-quality` 에 게이트 호출 추가 → 품질검사와 동시 판정
- 주간 `weekly-strategist` 가 Layer3 검증 + `CFG` 보정 담당

## 4. 자체 피드 검증 결과 (게이트 캘리브레이션)

기존 글 실측 판정 — 게이트가 정확히 "구멍"을 잡아냈다:

| 글 | 게이트 | 점수 | 막힌 곳 |
|---|---|---|---|
| 132 파킹통장 | 🔴 탈락 | 7 | **G6 저장 유발 없음**, 내부링크 0 |
| 128 종부세 1세대1주택 | 🔴 탈락 | 6 | **G6 저장 유발 없음**, 내부링크 0 |
| 126 두루누리 | 🟡 통과 | 6 | 저장장치 있어 통과, 노림수엔 가점 부족 |

**공통 처방 (전 글 적용 시 즉시 등급 상승):**
1. **G6 저장 유발 장치 의무화** — 상단 "금액·기한 한눈표" + 말미 "저장해두고 신청 직전 다시 보세요" 한 줄. → 대부분의 🔴를 🟡로.
2. **내부링크 2개** (S4) — 같은 시리즈 이전 글 연결. → 체류·연결 + 가점.
3. **고단가 브리지 주제**(S5) 비중↑ — 노출과 수익을 동시에.

## 5. 한 줄 운영 규칙

> **"노림수 글은 homefeed-gate 🟢 아니면 발행 안 한다. 발행 후 48h에 홈피드 유입 잡혔는지 본다. 그 데이터로 게이트를 매주 고친다."**

이 3문장이 홈판 노출을 요행이 아니라 **시스템**으로 만든다.

### 부록: 게이트가 못 보는 것 (수동 확인)
- 6-gram 중복률(25% 컷) → `/blog-quality` 의 중복검사로 별도 확인
- 썸네일 숫자 합성(S2 실물) → 게이트는 텍스트만 봄, Canva 작업은 수동
- 발행 골든타임 → frontmatter에 시간 없으면 게이트 미측정, 발행 시 수동 준수
- 실제 개인화 매칭 → Layer3 유입경로로만 확인 가능
