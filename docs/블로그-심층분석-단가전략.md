## 0. 결론 3줄

1. **검색 노출력은 이미 검증됨.** 종부세 1세대1주택 = 5.3만 경쟁 중 정확도 **1위**, 두루누리 3위, 파킹통장 5위. 콘텐츠 품질·신선도·키워드 매칭이 작동하고 있다.
2. **그런데 구조가 "트래픽 高 · 단가 低"다.** 지원금·복지 키워드는 검색량이 고단가 키워드의 **10~20배**지만, 광고주가 입찰을 거의 안 해 애드포스트 RPM(클릭단가)이 낮게 잡힌다.
3. **해법은 "피벗이 아니라 블렌드".** 지원금 글은 트래픽 엔진으로 유지하되, **이미 다루고 있는 절세·대출·연금·카드 클러스터(돈일기·사장님금융)를 고단가 광고 인벤토리 쪽으로 키운다.** 대출/보험 스팸 키워드 직접 경쟁은 금물(브랜드 훼손).

## 2. 검색 노출 실측 (정확도 sort 기준)

| 키워드 | 전체 경쟁글 | 머니브리핑 순위 | 발행일 |
|---|---|---|---|
| 종합부동산세 1세대 1주택 | 53,634 | **🥇 1위** | 5/31 |
| 두루누리 사회보험 지원 | 14,130 | 🥉 3위 (위는 세무사 블로그) | 5/31 |

→ 다만 정확도(sim) 순위는 신선도 가산이 큼. **시간이 지나도 순위를 유지하는지**는 체류·클릭(반응)이 좌우 → [홈피드 전략 문서](네이버-홈피드-노출전략.md)의 측정 루프와 연결.

## 3. 핵심 진단 — "왜 단가가 낮은가" (DataLab 근거)

최근 6개월 검색수요(상대비율, 100=최대):

| 키워드군 | 대표 키워드 | 검색수요(평균) | 광고 단가 |
|---|---|---|---|
| 지원금형 | 근로장려금, 두루누리 | **매우 높음 (5월 100)** | 🔴 낮음 |
| 보험형 | 실손보험, 운전자보험 | 낮음 (7~13) | 🟢 최고 |
| 대출형 | 대출 갈아타기, 주담대 금리 | 낮음 (4~7) | 🟢 높음 |
| 카드형 | 신용카드 추천 | 낮음 (3~4) | 🟢 높음 |

**구조의 정체**: 머니브리핑 트래픽의 주력인 지원금·복지 키워드는 **검색량이 고단가 키워드의 10~20배**다. 사람이 많이 온다.
하지만 "근로장려금 신청"을 검색하는 사람에게 붙일 **광고주가 거의 없다**(팔 상품이 없는 정책 정보). → 클릭당 단가가 바닥.
반대로 대출·보험·카드는 광고주가 클릭당 수백~수천 원을 입찰하지만 검색량이 적고 경쟁이 험하다.

> 즉 지금은 **"방문자는 많은데 1클릭당 돈이 안 되는"** 전형적 정보성 블로그 수익 구조다. 애드포스트를 막 켠 지금이 믹스를 조정할 적기.

## 4. 단가(CPC) 올리는 전략 — 핵심

### 원칙: 피벗 ❌ → 블렌드 ✅
지원금 콘텐츠(트래픽 엔진)는 그대로 두고, **고단가 광고가 붙는 주제의 비중을 늘린다.**

### 4-1. "브리지 키워드" — 브랜드 안 깨고 단가 올리는 교집합
머니브리핑이 **이미 신뢰도 있게 다룰 수 있으면서** 광고 인벤토리가 비싼 주제:

| 브리지 클러스터 | 붙는 광고주(고단가) | 이미 쓴 글 | 더 키울 롱테일 |
|---|---|---|---|
| **절세·세무환급** | 세무대리·환급서비스(삼쩜삼류) | 종소세 환급, 경정청구, 프리랜서 계산기 | "프리랜서 종합소득세 환급 후기", "종소세 신고대행 비용", "사업자 절세 컨설팅" |
| **연금·투자상품** | 증권사·연금·ISA | ISA 중개형, 연금저축 세액공제, 개인투자용국채 | "ISA 계좌 어디서", "연금저축 추천 증권사", "IRP 수수료 비교" |
| **대출·대환** | 핀테크·은행·대환 | 대환 갈아타기, 주담대 금리비교, 디딤돌·버팀목 | "전세대출 갈아타기 후기", "주담대 금리 낮추는 법", "보금자리론 vs 디딤돌" |
| **카드·신용** | 카드사·핀테크 | 신용카드 공제율, 신용점수 올리는법 | "연회비 아까운 카드 정리", "신용점수 올리는 카드", "체크카드 공제 한도" |
| **보험(연성)** | 보험GA(최고단가) | (없음) | "실손보험 청구 방법", "1세대 실손 전환 손익", "운전자보험 꼭 필요한 특약" |

> ⚠️ 보험·대출은 단가 최고지만 **레드오션 경고**: 실측 결과 "대출 갈아타기"는 23.8만 경쟁글, "운전자보험 비교" 1위 글은 대놓고 `[광고료 지원 게재 글]`(대출모집인·보험GA 리드젠 블로그). 정면 경쟁하면 ① 순위 못 뚫고 ② "또 광고글" 인상으로 브랜드 신뢰 훼손. → **"비교·추천"이 아니라 "청구방법·손익계산·후기" 같은 정보형 롱테일로 우회 진입.**

### 4-2. 단가 올리는 글쓰기 5가지
1. **고단가 주제는 "후기·손익계산" 프레임으로** — "운전자보험 비교"(스팸존)❌ → "운전자보험 특약, 진짜 필요한 것만 골라봤어요"✅
2. **글 안에 자연 검색의도 심기** — 절세 글 끝에 "환급은 ○○로 받았어요"처럼 상업 의도 문맥을 자연스럽게 → 관련 광고 매칭률↑ = RPM↑
3. **롱테일 우선** — "대출"❌ → "전세대출 갈아타기 중도상환수수료 계산"✅ (검색의도 명확 → CTR·광고관련성↑ → CPC·RPM 동반 상승)
4. **본문 길이 살짝 늘리기** — 고단가 주제는 1800~2200자로 광고 슬롯 확보 여지 (단 가독성 규칙 유지)
5. **시즌 고단가 선점** — 5~6월 종소세/장려금 끝나면 → 7월 재산세·자동차세, 11~12월 연말정산·종부세, 1월 실손 갱신. 캘린더로 미리.

### 4-3. 믹스 목표 (예시)
현재 추정 지원금·복지 60% / 재테크·절세·대출 40%
→ 3개월 내 **지원금 40% / 브리지(고단가) 60%** 로 점진 이동. 트래픽은 지원금 시즌글로 방어.

## 5. 키워드 풀 확장안

### 5-1. 확장 방식 (시스템 연동)
- 기존 `keyword-expand.js`(자동완성 2hop + Golden Score)에 **고단가 시드**를 주입하면 풀이 그쪽으로 증식한다.
- 아래 시드를 `keyword-bank/` 에 "고단가" 태그로 추가 제안 (원하면 바로 작업).

### 5-2. 고단가 시드 키워드 (브리지 클러스터별)
```
[절세·환급]  종합소득세 환급 후기 / 경정청구 셀프 / 프리랜서 세금 신고 / 사업자 절세 / 부가세 환급 / 양도세 계산
[연금·투자]  ISA 계좌 추천 / 연금저축 증권사 / IRP 수수료 / 퇴직연금 디폴트옵션 / 국채 투자 / 배당주 절세
[대출·대환]  전세대출 갈아타기 / 주담대 금리 비교 / 대환대출 한도 / 보금자리론 조건 / 신생아 특례대출 / 중도상환수수료
[카드·신용]  연회비 무료 카드 / 신용점수 올리기 / 카드 소득공제 / 체크카드 추천 / 자동차 할부 금리
[보험(연성)] 실손보험 청구 / 4세대 실손 전환 / 운전자보험 특약 / 태아보험 / 암보험 비교
```

### 5-3. 트래픽 엔진(저단가지만 유지) — 시즌 캘린더
```
6월  재산세 · 종부세 합산배제 · 근로/자녀장려금 지급일
7월  자동차세 연납 · 재산세 2기 · 휴가비 지원
9월  추석 민생지원 · 종부세 특례신청
11~12월  연말정산 미리보기 · 내년 지원금 변경
1~2월  연말정산 · 실손 갱신 · 설 민생
```

## 6. 홈판(홈피드) 노출 블로그 벤치마킹 → 적용점

검색·경쟁 데이터에서 읽은, 홈피드/상위노출 블로그의 공통 패턴과 머니브리핑 적용안:

| 벤치마크 패턴 | 잘하는 블로그 | 머니브리핑 적용 |
|---|---|---|
| **경험형·후기형 제목** | 대출/보험 상위 블로그 전부 "후기/실제 경험" | ✅ 이미 전환 중 → 전 카테고리로 확대 |
| **숫자·금액 구체화** | "보험료 80% 줄었어요", "12억 공제" | ✅ 제목에 숫자 1개 고정 + 썸네일에도 숫자 합성 |
| **전문성 시그널** | 세무사·전문 블로그가 정보형 상위 독점 | 출처·근거(법령·고시) 명시 유지 = 신뢰 차별화 |
| **질문형 후킹** | "지금 신청해도 될까요?" | ✅ 이미 사용 → 홈피드 호기심 클릭에 유리 |
| **저장 유발 구조** | 신청기한·서류 체크리스트 | 상단 "한눈표" + 말미 "저장하세요" 의무화 |

> 머니브리핑의 차별화 포인트: 리드젠 블로그(대출모집인·보험GA)는 단가는 높지만 신뢰가 약하다. 머니브리핑은 **"출처 있는 에디터"** 포지션이라, 같은 고단가 주제를 **신뢰형 정보 콘텐츠로** 먹으면 리드젠과 다른 자리에서 노출된다(홈피드는 신뢰·체류를 본다).

## 7. 실행 우선순위 (애드포스트 켠 첫 달)

1. **[즉시] 측정 시작** — 애드포스트 보고서에서 글별 **RPM(클릭단가)** 확인 → "어떤 주제가 단가 높은지" 실데이터 축적. (이게 4장 전략의 검증 루프)
2. **[1주] 브리지 글 주 3개 투입** — 절세·환급/연금/대출 클러스터에서 후기형으로. 저단가 지원금 글과 병행.
3. **[2주] 고단가 시드 키워드 풀 주입** — `keyword-bank`에 고단가 태그 추가, 파이프라인이 그쪽으로 증식하게.
4. **[3주] 썸네일 숫자화 + 저장 유도** — 홈피드 CTR·체류 동시 공략.
5. **[4주] RPM 상위 주제 더블다운** — 1번에서 단가 높게 나온 주제 비중↑, 낮은 주제는 트래픽용으로만.

## 부록: 데이터 한계
- 애드포스트 실제 RPM·방문자수는 본인 계정 통계에만 있음 → 7장 1번으로 수집 시작해야 4장 믹스 전략이 추측→실측으로 전환됨.
- 검색 순위는 정확도(sim) sort 기준 = 신선도 가산 포함. 통합검색 실제 노출과 다를 수 있음.
- CPC 단가 비교는 키워드 상업성 기반 정성 추정(애드포스트 단가는 비공개).
