# 네이버 홈피드(홈판) 노출 전략 — 머니브리핑

> 작성 기준일 2026-06-01 · 대상: 네이버 앱 홈 / 홈피드 메인 추천 영역 노출

---

## 0. 한 줄 요약

머니브리핑은 **발행량(6~7개/일)·4개 시리즈 일관 운영·모바일 가독성**까지 이미 홈피드에 유리한 토대를 갖췄다.
지금 막혀 있는 두 가지는 ① **반응 데이터(저장·체류·클릭) 미수집** ② **카테고리 태그 누락 41%** 다.
홈피드는 검색과 달리 "반응으로 뜨고, 주제가 명확한 블로그"를 밀어주는 영역이라, 이 둘만 메우면 노출이 구조적으로 올라간다.

---

## 1. 홈피드는 검색 노출과 "완전히 다른 게임"이다

| 구분 | 검색 노출 (통합검색/VIEW) | 홈피드 노출 (앱 메인 추천) |
|---|---|---|
| 트리거 | 사용자가 **키워드를 입력**할 때 | 사용자가 **그냥 앱을 열었을 때** |
| 핵심 알고리즘 | C-Rank(출처 신뢰)+DIA+(문서 품질) | 개인화 추천(관심사 매칭) + **초기 반응 신호** |
| 결정 요인 | 키워드 적합·전문성·정보성 | **발행 직후 1~2시간 반응속도**(CTR·체류·저장) |
| 핵심 행동 유도 | "검색해서 찾아온 사람을 만족" | "안 찾던 사람을 멈춰 세우기 + 저장시키기" |

→ **시사점**: 검색용 글(정보 충실)과 홈피드용 글(반응 유발)은 설계가 다르다.
지금까지 머니브리핑 글은 "검색 최적화"에 가깝다. 홈피드를 노리려면 **썸네일·제목·도입부·저장 유인**을 별도로 설계해야 한다.

---

## 2. 현황 진단 (실데이터 기반)

**발행 데이터 (2026-05-11 ~ 06-01, 총 141개) — 블로그 실제 카테고리(frontmatter) 기준**

| 카테고리 | 누적 | 태그분 비중 |
|---|---|---|
| 사장님 금융 | 26 | 31% |
| 정책이슈 | 23 | 28% |
| 돈 일기 | 20 | 24% |
| 육아경제 | 14 | 17% |
| **미분류(태그 없음)** | **58** | — |

> 태그가 붙은 83개만 보면 4개 시리즈가 **31/28/24/17%로 거의 균등**하다. 다만 전체의 **41%(58개)가 카테고리 태그 없음** — 대부분 초기 글(#1~80대)과 이번주 활성분에 `category` 필드가 빠져 있다.
> (참고 — 주제 키워드 기준으로 다시 묶으면 절세·세금/정부지원금이 약 60%로 가장 큼. 즉 "콘텐츠 소재"는 세금·지원금에 쏠려 있고, "블로그 카테고리"는 4시리즈로 나뉘어 있는 이중 구조다.)

**강점 (홈피드에 유리)**
- ✅ **시리즈 운영**: 돈일기·사장님금융·정책이슈·육아경제 4축으로 꾸준히 쌓는 중 → 각 시리즈가 C-Rank '전문성'을 따로 적립.
- ✅ **발행 일관성**: 매일 다작 → 노출 기회 자체가 많음.
- ✅ **저장각 주제**: 정부지원금·절세·신청기한은 본질적으로 "저장(스크랩) 유발" 주제. 홈피드 최강 신호인 저장에 최적.
- ✅ **모바일 가독성 규칙(v4.0)**: 짧은 문장·빈 줄·친근체 → 홈피드 체류시간에 직접 기여.

**약점 (지금 막혀 있는 곳)**
- ❌ **반응 데이터 미수집**: 어떤 글이 홈피드에 떴는지, 저장이 몇 건인지 측정이 없다. 홈피드는 반응 기반인데 반응을 안 보고 있음 → 개선 루프 부재.
- ❌ **카테고리 태그 41% 누락**: 미분류 58개. 블로그 카테고리는 알고리즘이 "이 블로그 전문 분야"를 판단하는 핵심 신호인데, 절반 가까이가 무태그면 4시리즈의 전문성 신호가 희석된다. → **소급 태깅 + 발행 시 category 필수화** 필요.
- ⚠️ **전문성 4분할**: 4시리즈가 균등(31/28/24/17%)해서 "한 우물" 신호는 약하다. 홈피드 반응이 가장 좋은 1~2개 시리즈를 데이터로 찾아 비중을 더 싣는 게 유리.
- ⚠️ **다작의 함정**: 6~7개/일은 노출 기회는 많지만, 썸네일·제목 공들임이 분산된다. 홈피드는 "평균"이 아니라 "한 방 터진 글"이 끌고 간다.
- ⚠️ **썸네일 전략 부재**: 홈피드는 90% 썸네일+제목으로 클릭이 결정된다. 현재 이미지 규칙(인물·텍스트 없는 일러스트)은 검색엔 무난하나 홈피드 CTR엔 약하다.

## 3. 홈피드 노출을 만드는 5대 신호 + 액션

홈피드 추천은 발행 직후 소수에게 먼저 노출(테스트) → 반응 좋으면 노출 확대(증폭)되는 구조다. 그래서 **초기 반응 5신호**가 전부다.

### 신호 1. CTR (썸네일·제목 클릭률) — *가장 중요*
- **썸네일**: 일러스트에 **큰 숫자/키워드 1개**를 Canva로 합성. 예) "258만원", "7월 31일 마감", "1주택 0원".
  → CLAUDE.md의 "발행물엔 텍스트 없는 일러스트" 규칙은 검색용. 홈피드용 썸네일은 **숫자 1개만** 얹는 예외를 허용 권장.
- **제목 공식**: `[대상] + [숫자/기한] + [손실회피]`
  - ❌ "종합부동산세 1세대 1주택 정리"
  - ✅ "1주택자, 종부세 0원 만드는 법 (6월 1일 기준)"
  - ✅ "이거 모르면 258만원 날립니다 (신청 7/31 마감)"

### 신호 2. 저장(스크랩) — *홈피드 증폭의 핵심*
- 정부지원금·절세는 "나중에 봐야지" 저장 유발 1순위.
- **본문에 저장 유도 장치 의무화**:
  - 상단에 "📌 신청기한·금액 한눈표" (저장 목적의 표 1개)
  - 마지막에 "이 글은 저장해두고 신청 직전에 다시 보세요" 한 줄
- 체크리스트·신청서류 목록·계산 예시 = 저장률↑

### 신호 3. 체류시간
- 도입부 3줄에서 "내 얘기다" 후킹 (손실회피 카피 유지).
- 중간 이탈 방지: 소제목(인용구) 사이 간격 일정하게, 스크롤 리듬 유지 (이미 v4.0로 잘 됨).
- 1500~2000자 유지 OK. 너무 길면 홈피드 체류 완독률 하락.

### 신호 4. 발행 직후 초기 반응 속도
- 홈피드 테스트 노출은 발행 직후 몇 시간이 승부. **발행 시간을 타깃 독자 활동시간에 맞춰라.**
  - 금융/지원금 독자 = 출근길(07~09시), 점심(12~13시), 밤(21~22시).
  - 현재 06:00 파이프라인은 "생성"이고, **실제 발행 시각**을 위 골든타임으로 옮기는 게 핵심.
- 다작이면 **하루 1~2개를 골든타임 "노림수"로 지정**해 집중 발행.

### 신호 5. 주제 일관성 (C-Rank 전문성)
- **카테고리 태그 누락 41%부터 해결**: 미분류 58개를 4시리즈 중 하나로 소급 태깅하고, 발행 시 `category` 필드를 필수화한다. (가장 시급)
- 4시리즈(돈일기/사장님금융/정책이슈/육아경제)는 5개 이내로 고정 유지. 블로그 카테고리명도 알고리즘이 읽으므로 명확하게.
- 측정 후 **홈피드 반응이 가장 좋은 1~2개 시리즈에 발행 비중을 더 싣는다** (균등 4분할 → 강점 시리즈 가중).

## 4. "홈피드 노림수" 글 설계 (주 2~3개 집중)

다작은 유지하되, 주 2~3개는 아래 풀세팅으로 만든다.

```
□ 제목: [대상]+[숫자/기한]+[손실회피] 공식
□ 썸네일: 일러스트 + 큰 숫자 1개 (Canva 합성)
□ 도입부 3줄: "내 얘기다" 후킹 (손실회피)
□ 상단 저장표: 금액·기한·대상 한눈표 1개
□ 본문: 신청방법 단계 + 계산 예시 + 체크리스트
□ 말미: "저장해두고 신청 직전 다시 보기" 1줄
□ 발행시각: 07~09 / 12~13 / 21~22 골든타임
□ 발행 후 24h: 통계에서 저장·조회 기록 → 측정표 입력
```

**노림수 후보 주제 (저장각 + 시즌성)**
- 6월: 종부세(과세기준일 6/1), 근로·자녀장려금 정기신청(5~6월), 재산세
- 상시 떡상주제: "○○만원 받는 법", "신청 마감 D-○", "1주택자 절세"

## 5. 측정 루프 (이게 없으면 위 전략이 추측에 그친다)

홈피드는 반응 기반 → **반응을 봐야 개선된다.** 네이버 블로그 통계는 API가 없어 수기 입력이 필요하다.

**주간 루틴 (일요일, weekly-strategist와 연계)**
1. 네이버 블로그 통계 → 지난주 글별 **조회수·평균체류·유입경로** 확인
2. 유입경로에 **"네이버 홈피드/추천"** 비중이 있는 글 = 홈피드에 뜬 글 → 표시
3. 글별 **스크랩(저장) 수** 기록
4. "홈피드 뜬 글"의 공통점(제목형·썸네일·발행시각·주제) 역추출 → 다음주 노림수에 반영

> 다음 단계 제안: 이 입력을 자동 집계하는 **성과 입력 템플릿**(`output/weekly-analysis/<날짜>/홈피드-성과.md`)을 만들면, weekly-strategist가 매주 "홈피드 승률"을 리포트하게 할 수 있다. (원하면 만들어 드림)

## 6. 4주 실행 로드맵

| 주차 | 목표 | 핵심 행동 |
|---|---|---|
| 1주차 | 측정 시작 | 네이버 통계에서 유입경로 '홈피드' 글 식별 시작. 노림수 주 2개 시범. |
| 2주차 | 썸네일 실험 | 노림수 글에 숫자 썸네일 적용, CTR 체감 비교. 발행시각 골든타임 이동. |
| 3주차 | 저장 최적화 | 상단 저장표·말미 저장유도 전 글 적용. 저장률 변화 측정. |
| 4주차 | 패턴 고정 | 홈피드 뜬 글 공통점 표준화 → "노림수 템플릿" 확정, 다작에 부분 이식. |

## 7. 지금 당장 바꿀 3가지 (우선순위)

1. **발행 시각을 골든타임으로** (07~09/12~13/21~22). 가장 싸고 효과 큰 변경.
2. **노림수 글 썸네일에 숫자 1개 합성** — 홈피드 CTR 직격.
3. **저장 유도 장치(상단 표 + 말미 1줄) 의무화** — 홈피드 증폭 신호 확보.

> ⚠️ 본 문서의 알고리즘 설명은 네이버가 공식 수치를 공개하지 않으므로, 공개된 동작 원리 + 블로그 운영 통설 기반 추정이다. 최종 검증은 5장의 측정 루프(실제 유입경로 데이터)로 한다.
